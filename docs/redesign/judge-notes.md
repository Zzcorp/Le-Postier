# Judge scores

Winner: Cachet — Cabinet de curiosités / musée

- Cachet — Cabinet de curiosités / musée: elegance 9, fit 9.5, feasibility 8.5 — Strongest provenance story: Semeuse stamps as semantic colors, passe-partout + cartel system, warm sepia shadows, brand ochre retained. Best fit for older French collectors (17px Garamond body, museum grammar). Slightly heaviest CSS surface (4 families, dual light/dark), but every value is final and implementable.
- Cimaise — Galerie contemporaine: elegance 9.5, fit 8, feasibility 9.5 — Most disciplined spec of the three: one accent spent like money, mat-brighter-than-wall lighting trick, native <dialog>, unboxing beat. But the contemporary-gallery coolness under-serves the sentimental postal/social feature and the older audience; 16px sans body is less generous than Cachet's 17px serif.
- Papeterie Postale: elegance 8.5, fit 9, feasibility 9 — Best La Poste narrative and the single best interaction (coup de tampon); only CVD-validated chart palette. But swapping the action color from brand ochre to bleu postal abandons an established identity, and four postal motifs risk scrapbook without strict rationing.
